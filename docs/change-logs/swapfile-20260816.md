# Swap File - 2026-08-16

Added an 8 GiB swap file to provide emergency memory headroom for transient
container and future workload spikes.

## Configuration

- Path: `/swapfile`
- Size: 8 GiB
- Ownership and mode: `root:root`, `0600`
- Persistent fstab entry: `/swapfile none swap sw 0 0`
- Kernel swappiness left at the Debian default; no additional memory-policy
  tuning was introduced.

## Verification

- Activated the file with `swapon` without rebooting.
- Confirmed `swapfile.swap` is active through systemd.
- Confirmed `/etc/fstab` parses without errors; the regular-file swap warning
  from `findmnt --verify` is expected.
- Confirmed Node Exporter exposes `node_memory_SwapTotal_bytes` and
  `node_memory_SwapFree_bytes` at 8 GiB.
- Confirmed the Borg job archives explicit source paths and does not include the
  root-level swap file.
- Preserved the pre-change fstab as `/etc/fstab.pre-swap-20260816`.
